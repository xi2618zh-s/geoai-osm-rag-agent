Local Python execution

Change the question.
Run the calculation.

The included Lund snapshots need no model, API key or large data download. The website shows an already saved analysis; the local app computes a new one.

Install and start

Use Python 3.10 or later in a checkout containing the school explorer. Use the repository version containing this explorer. 

git clone https://github.com/xi2618zh-s/geoai-osm-rag-agent.git
cd geoai-osm-rag-agent
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-demo.txt
.venv\Scripts\python scripts/run_demo.py

Open http://127.0.0.1:8000/explore. If that port is occupied, add --port 8017 and use that port in the address. On Linux/macOS use .venv/bin/python. The app binds to loopback only.

Choose a distance above zero and at most 2,000 m, one of the four SCB age bands (0–4, 5–9, 10–14, 15–19), and at least one child. Only Lund is supported. Preview the data and plan, then run. Editing a field invalidates the previous preview. The page shows actual checks and a new result, including valid empty results.

Keep the result

Download CSV, projected GeoJSON, the standalone HTML report or the JSON calculation record. Files live in output/demo_runs/<run_id>/, separated for each execution. They persist across restarts with no automatic expiry. Temporary registries are removed after exports. Keep the run folder to retain its report.

Distances use EPSG:3006 metres from grid polygons to extracted school points. Convert GeoJSON to EPSG:4326 before use in longitude/latitude applications. Straight-line distances do not measure a walk; edge cells and incomplete school information limit interpretation.

Use the same service from a terminal

.venv\Scripts\python scripts/run_analysis_demo.py --distance-m 1000 --age-band 5-9 --minimum-children 10

The API accepts structured fields at POST /api/analyses/preview and POST /api/analyses/run. It supports this included school question, not unrestricted natural-language analysis. Missing or invalid parameters need correction. Data or report validation failure does not produce a successful report.

OSM place queries

The separate query interface uses the full environment, Ollama, an external Sweden PBF and osmium CLI. Start it separately: 

scripts\setup_env.cmd
conda run -n geoai_project_env python scripts\fetch_osm_data.py
ollama pull qwen2.5:3b
scripts\run_local.cmd

Open /ui on that server. The lightweight school server does not expose the OSM query endpoints. See the repository's OSM integration guide.

Code and data licences are recorded in the repository. New public real-time execution would require a separate backend deployment.
