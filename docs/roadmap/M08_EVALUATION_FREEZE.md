# M08 validation and bounded recovery evaluation freeze v1

- Frozen: 2026-10-06 (Asia/Shanghai), before M08 production code.
- Scope: public synthetic offline fixtures and injected failures over M07 static plans plus M04 DatasetRef tools. No live model, network, large PBF, hidden tasks or transport isochrone claims.
- Static entry: only M07 status=plan proposals revalidated against the original M07PlanRequest may execute. Dataset role bindings are opaque DatasetRef objects resolved through LocalDatasetRegistry.
- Cases (16): four clean first-pass tasks (search, filtered search, within distance, aggregate count); four recoverable faults (transient timeout, declared CRS repair, declared geometry repair, declared alternate DatasetRef); eight nonrecoverable or guarded faults (missing output, stale/hash-corrupt output, unexpected empty result, invalid geometry without repair, excessive feature count, tool unavailable, unsupported replan, false numeric conclusion). Each case has an expected stable failure class and bounded action trace.
- Primary metrics: first-pass success / 16; recovered success / 4 recoverable injected faults; correct error classification / 12 injected faults. Thresholds: clean first-pass 4/4, recovered >=3/4, error classification >=11/12; all eight guarded faults must never be reported as success. For a clean task, first-pass success means no recovery action; fault recovery is reported separately.
- Bounds: same-parameter transient retry at most once per step; declared repair/fallback at most once per role and failure; replan at most once per run; tool invocations at most 24. Every attempted action records reason, action, result and input/output DatasetRef IDs. Failure yields partial result with limitation; no validator mutation of source data or computed values.
- Validation: tool success, current readable DatasetRef with SHA verification, vector/schema/CRS/geometry, explicit empty policy and feature cap, final user count bounds, and consistency of numeric conclusion claims with the final dataset. Unknown tool, hidden path or unvalidated plan never reaches a handler.
- Fixed small fixture provenance: existing project-authored M04c GeoJSON plus M08 synthetic derivatives under data/fixtures/m08/v1. No M03 release or receipt is modified. M03 Phase 2 catalog-informed public query limitation remains.
