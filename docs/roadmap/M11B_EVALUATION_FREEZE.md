## 评分合同 v2.0

- v2.0 任务/预测独立于 M11a v1.0，保留 v1.0 加载与评分行为；未知字段拒绝。success、clarification、error、partial 状态分明；非成功的原因码必须精确匹配。partial 不能冒充 success，即使部分要素或数字正确。
- 必需字段按键和值精确比较，缺失与错误分别记录。必要语义步骤按顺序子序列评分；真实 M04 工具名按完整调用序列精确评分，额外、缺失、换序均失败。评分只读取预测中的结构化轨迹，不执行预测提出的工具或路径。工具名必须属于 M04 allow-list。
- Feature ID 是集合：双方皆空时 P/R/F1=1；仅一方为空时均为 0；否则按 TP/预测数、TP/参考数和调和平均。重复 ID 拒绝。成功结果缺失字段、几何、数值分别记 0，不静默忽略。总通过需所有适用组件通过；部分分仅作诊断。
- 数值：|actual-reference| <= max(abs_tol, |reference|*rel_tol)；数量整数精确，面积平方米和距离米均为 abs_tol=1e-6、rel_tol=1e-6。NaN/Inf 拒绝。几何必须显式相同 CRS：面用真实 Shapely 面积 IoU（阈值 0.999999），非面用拓扑相等或 Hausdorff 距离 <=1e-6；双方空等价，一侧空不等价；无效几何不通过，不自动修复；CRS 缺失或不等价不通过。bbox 不能替代真实几何。
- 排名 nDCG 仅用于未来明确支持且独立标注的任务；本版 rank 必须返回 unsupported_rank，不得冒充已支持。非排名任务不计排名指标。
- 预设验收：160/160 合同可解析，ID/查询无重复，144/144 参考答案由真实 M04 allow-list 调用并可逐字节复建，16/16 澄清/不支持分类准确；评分边界专项全过，完整离线不少于 437，历史审计全过。这是构建/评分正确性门槛，不是系统任务成功率。

## 风险与边界

- 小型公开 Fixture 的变体相关，不能视为 160 个独立地理来源或开放域泛化。
- M03 Phase 2 公开查询是 catalog-informed 内部评测。GTFS 固定站点缓冲不是真实交通等时圈；本任务集不推断真实交通时间。
## 隐藏切分补充冻结（在生成隐藏内容前，2026-10-07）

- 初版 160 条公开 dev v1 保留原位且不覆盖。为满足实施计划“增加隐藏测试集”，总任务集定为 200 条：公开 dev 160 + 独立 private test 40。
- private test 使用不同的合成坐标与随机化 Feature ID，在被 Git 忽略的 benchmarks/data/test/private/ 保存输入、任务、私有 seed 和答案。公开 test 目录只发布不含查询/答案/seed 的 hash receipt 与保管规则。私有内容不进入开发 Fixture、Prompt、知识别名、日志或公开报告。
- 40 条分布：search、within_distance、nearest、within、spatial_join 各 8。专用源数据仍是项目作者合成 CC0；M04 allow-list 实际执行生成答案。该内部隐藏切分与公开 M04b Fixture 有结构关联，只能证明相对开发查询隔离，不能称外部独立专家标注。正式 test 评分须锁定模型/Prompt/配置后执行，M11b 仅验证数据与评分合同，不运行 M11c 基线。
