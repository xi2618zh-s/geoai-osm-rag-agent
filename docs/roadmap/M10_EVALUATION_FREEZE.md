# M10 result expression evaluation freeze v1

- Frozen: 2026-10-06 (Asia/Shanghai), before M10 production code. Public synthetic offline evaluation over existing M04c fixture and actual M07/M08 validated outcomes, with no live model or network.
- Cases: 12 records in benchmarks/data/dev/m10_result_cases_v1.jsonl, four search, four distance coverage, four verified count comparisons. Comparison satisfies the planned ranking/comparison template; ranking remains unsupported without a registered deterministic rank tool. The user-visible report must not imply ranking or a real transport isochrone.
- Main metrics and thresholds: complete AnalysisResult contract 12/12; every report numeric token traceable to a metric whose value is derived from verified DatasetRef or the accepted plan 12/12; valid multi-layer map and legend 12/12; GeoJSON and CSV downloads whose contents match the verified output 12/12; three templates each 4/4. All thresholds are exact because the fixtures and renderer are deterministic.
- Hard gates: reject M08 partial or stale/tampered DatasetRef; reject fabricated metric values, undeclared report metric placeholders, literal numeric report claims, unsafe markup/CSV formula injection, unknown layer source, and a comparison without both verified outcomes. No LLM-generated number is accepted. Source/version/hash and step evidence appear in every successful result.
- Browser acceptance: a standalone local HTML demo opens without manual file edits or external CDNs, shows multiple switchable geometry layers, legend and feature popup, metric chart, table, source/step/assumption/limitation sections, and working GeoJSON/CSV download links. It may use SVG instead of online basemap tiles, with coordinate reference clearly labeled. Rendered report and chart read only contracted metrics. At least one test checks the HTML structure and embedded contract; browser visual QA is a separate check.
- Preview cap: map/table may show a bounded subset but downloads contain the full verified result; counts always use full DatasetRef, with truncation disclosed. No new dependency or old public contract replacement; any new output contract and additive route require ADR and compatibility audit.
- M03 Phase 1/2 releases and public receipts remain immutable; M03 Phase 2 queries are catalog-informed internal evidence. Fixed GTFS stop buffers do not represent travel-time isochrones.
