# M03 Phase 2 retrieval query release

This public release contains 410 development queries (English and Chinese for every tag) and 205 public_eval challenge queries (one per tag). The total is 615 distinct queries. Both cohorts, retained 100 and new 105, are covered. public_eval is public, not hidden, and may be used once per frozen experiment after configuration freeze.

Queries are project-authored and Codex-assisted. Name and alias prompts use catalog names or aliases. Scenario challenges are catalog-informed paraphrases, with reviewed exceptions for awkward automatic name removal. They are separate query records and have no exact full-text overlap with the catalog or each other; this does not establish independent external annotation. Results should be interpreted with that limitation.
