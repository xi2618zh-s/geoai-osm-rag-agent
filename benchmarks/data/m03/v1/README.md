# M03 retrieval evaluation data v1

This directory contains a public development set (200 queries) and a public evaluation set (100 challenge queries). The public_eval split is not a hidden test set and must be run only once after configuration freeze for an experiment version.

Each of the 100 tags has one English and one Chinese dev query. Each tag has one public_eval challenge; exactly 25 use a catalog alias, and the other 75 contain neither the target name nor its aliases. All queries record authoring method and Codex assistance.
