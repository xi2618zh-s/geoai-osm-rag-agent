## Limitations

- 120/160 validator strict is only the entry gate to the sealed private evaluation, not a claim of improvement. Single-dataset buffer stays in the denominator and is unsupported; rank is unsupported.
- M11b v2.0 references and the strict scorer do not record or check per-region aggregate values (aggregate tasks are scored on tool path, status, region set, geometry and CRS).
- Clean data cannot show retry/replan recovery benefit. Prompt examples include public dev tasks and dev-derived paraphrases, so public dev numbers are optimistic for unseen phrasing.
